## ✨ Cinematic Features
- **Volumetric Light & Stardust Titles**: Floating particles and converging stardust letters on startup.
- **Web Audio Soundscapes**: Custom synthesized celebratory sounds, chimes, clock beeps, box explosions, and chord progressions.
- **3D Floating Polaroids**: Hover-responsive tilt cards showcasing precious chapters.
- **Memory Galaxy**: A scroll-revealed, interactive spiral galaxy constellation of memory stars.
- **Animated Magic Cards**: Animated cards containing a Mother's Blessing, transitioning into Mohan's custom note with magic sounds and stardust particle effects.
- **Custom Admin Console**: Accessible via `/admin/`, allows dynamic overrides of wishes text that load instantly via `localStorage`.

## 🚀 Local Customization
To customize wishes:
1. Open the `/admin/` route in your browser (e.g. `https://<your-username>.github.io/Birthday/admin/`).
2. Input the customized wishes text for Mother's Blessing or Mohan's note.
3. Click **Save Changes** and reload the main website to see your modifications live!
